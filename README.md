# CodSoft Internship Projects

In this repository, you can find various projects on machine learning and data analysis tasks done in the CodSoft Internship.

---

## Task 1: Data Cleaning & Preprocessing
* **Purpose:** Cleaning and preprocessing of the raw data through handling missing values, standardization of formats, and dealing with anomalies.
* **Method:** Profiling of the data, filling gaps, removing outliers, and formatting of the structure.
* **Tools Used:** Python, Pandas, NumPy
* **Location:** `/CODSOFT_TASK1datacleaning.ipynb`

---

## Task 3: College Placement Prediction & Dashboard
* **Purpose:** Predicting college placement of students based on demographic information, performance and skills.
* **Method:** Data profiling, categorical encoding, and classification modelling.
* **Tools Used:** Scikit-Learn, Pandas, Seaborn, Matplotlib
* **Location:** `/CODSOFT_TASK3_College_Placement_Dashboard`

---

##  Task 4: Customer Spending & Sales Prediction
* **Purpose:** Predicting sales spending from customers behavior, recency and transactions.
* **Method:** Categorical encoding, train-test splitting and regression modeling with Linear Regression and Random Forest Regressor.
* **Tools Used:** Python, Scikit-Learn, Pandas, Matplotlib
* **Location:** `/CODSOFT_TASK4_Sales_Prediction`
